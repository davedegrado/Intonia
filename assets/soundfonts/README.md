# SoundFont

Place the production piano SoundFont here as `piano.sf2`.

## License status: NOT VERIFIED ⚠️

The current `piano.sf2` has no identifiable metadata (bank name "User Bank",
created with an E-mu/SFEDT editor): its origin and license cannot be verified.
**Replace it before publishing to the stores.**

Recommended alternatives with store-compatible licenses:

- **GeneralUser GS** (S. Christian Collins) — free license, explicitly allows
  commercial use and redistribution. Extract the piano preset to keep size down.
- **Salamander Grand Piano** (Alexander Holm) — CC-BY 3.0, commercial use OK
  with attribution in the app credits (needs conversion to SF2).
- **FluidR3_GM** — MIT license. Extract the acoustic grand preset.

After replacing the file, credit the author in Settings → Info.
